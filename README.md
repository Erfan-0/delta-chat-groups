## How to Contribute

1. Fork this repository.
2. Add your channel to the appropriate category in the table below.
3. Submit a Pull Request.
4. Wait for review and merging.

Please make sure to include:  
- **Channel Name**  
- **Channel Link**  
- **Description** (1–2 lines)  
- **Category** (choose from the tables below)
